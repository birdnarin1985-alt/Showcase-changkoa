## 🌟 Overview

The **Architectural Blueprint CAD Engine** is a professional-grade, web-based technical drawing and 3D simulation tool. Designed with the **Golden Ratio ($\Phi = 1.618$)**, it bridges abstract mechanical concepts with precise parametric wireframe visualization. 

Optimized for mobile touchscreens and desktop browsers, this application requires **zero software installation** and provides instant SVG blueprint generation and single-page A4 technical printing.

---

## ✨ Key Features

* **⚙️ 6 Industrial Engineering CAD Models:**
  1. *Poultry Feeder Hopper (Conical sheet-metal assembly with gravity ports)*
  2. *Involute Spur Gear (Parametric polar involute teeth with central web spokes)*
  3. *3-Phase AC Voltage Waveform (Synchronous polyphase alternating power matrix)*
  4. *3D Structural Truss Node (6-axis orthogonal space frame and spherical hub)*
  5. *Ruled Hyperboloid & Dual-Helix Tower (Doubly-ruled architectural structure)*
  6. *Quantum Toroidal Magnetic Flux (Chirality vector field confinement)*

* **🎨 Multi-Theme Engineering Palettes:** Switch instantly between *Cyan Blueprint*, *Bio-Green Technical*, and *Amber Radar* themes.
* **📏 Parametric Real-Time Controls:** Adjust orbit rotation angles ($360^\circ$), perspective elevation tilt, scaling factors, and custom mechanical dimensions on the fly.
* **📐 Strict 1-Page A4 Print Engine:** Generates professional ISO-128 technical drawing sheets complete with Title Blocks, DWG numbers, revision tracking, and exact $140\,\text{mm}$ Safari-proof single-page lock.
* **💾 Vector SVG Export:** Export clean, scalable vector graphics directly from the viewport for CAD software integration.
